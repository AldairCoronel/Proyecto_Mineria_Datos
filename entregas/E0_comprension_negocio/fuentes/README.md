# Evidencia de las fuentes citadas

Las instrucciones permiten el stakeholder simulado **únicamente** si las respuestas están fundamentadas en fuentes verificables citadas en la bitácora. Esta carpeta guarda el respaldo de esas fuentes, para que sigan siendo consultables aunque una URL cambie o desaparezca.

## Qué archivar aquí

Una captura o PDF por cada fuente de `fuentes.qmd`, nombrada con su número:

```
01_datos_abiertos_metro.pdf          # ficha del dataset: cobertura, licencia, aviso retroactivo
02_datos_abiertos_metrobus.pdf
03_diccionario_datos_metro.png       # los campos fecha, anio, mes, linea, estacion, afluencia
04_afluencia_preliminar.png
05_stc_afluencia_por_estacion.pdf
06_infobae_estaciones_2024.pdf
07_milenio_linea2_2024.pdf
08_eluniversal_hora_pico.pdf
09_elgrafico_linea1.pdf
10_elfinanciero_reapertura_l1.pdf
11_infobae_reapertura_l1.pdf
12_movilidad_covid19.png
13_waze_for_cities.png
```

## Cómo archivar

En el navegador: **Imprimir → Guardar como PDF**. Conserva la URL y la fecha en el pie de página, que es justo lo que acredita la consulta.
